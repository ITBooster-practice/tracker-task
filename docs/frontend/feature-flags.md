# Runtime feature flags на frontend

Снимок загружается через существующий Axios-клиент с cookie-сессией и refresh-flow. `@repo/types` содержит общие схемы; клиент проверяет ответы API. ETag позволяет использовать прежний снимок при 304.

`FeatureFlagsProvider` хранит снимок и статус в TanStack Query и предоставляет React-контекст. `useFeature(key)` и `hasFeature(snapshot, key)` учитывают зависимости: tasks требует projects; boards требует projects и tasks. Отсутствующий ключ закрыт. Контекст не хранится в localStorage и не разделяет пользователей через серверный singleton.

Provider получает уведомления SSE с HttpOnly cookie, без токенов в URL. При новом номере версии он отменяет устаревшую загрузку и повторно запрашивает данные, а также обновляет список/аудит панели. Повторные и старые версии не вызывают лишний запрос. После разрыва соединения или истечения JWT повторное подключение сначала проходит существующий API refresh-flow; retry с задержкой 1–30 секунд. При размонтировании соединение и таймер закрываются.

`FeatureGate` показывает нейтральную загрузку, ошибку с повтором или недоступность раздела. После ошибки refresh даже старый включённый снимок не разрешает отображение функции.

Для разработки без API можно явно задать `NEXT_PUBLIC_FEATURE_FLAGS_DEV_FALLBACK=true` при `NODE_ENV=development`: показываются четыре начальных раздела с предупреждением о локальном режиме. В production, включая stage, этот fallback недоступен. Он не предоставляет права разработчика и не обходит защиту API.

Серверные layouts проектов и задач, страницы boards/settings и перехваченная модальная страница создания задачи проверяют актуальный снимок с cookie-сессией. Закрытый раздел возвращает 404 при прямом открытии URL. React FeatureGate дополнительно закрывает уже открытый раздел после уведомления. Кэш React ограничен одним серверным render-запросом. Меню и выбор проекта используют тот же runtime-снимок; ссылка `/admin/feature-flags` видна только разработчику системы.

Проверки backend и жизненный цикл: [feature flags](../backend/feature-flags.md).
