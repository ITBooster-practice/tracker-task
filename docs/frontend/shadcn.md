# shadcn/ui

В проекте используется [shadcn/ui](https://ui.shadcn.com/) — коллекция переиспользуемых компонентов на основе Radix UI и Tailwind CSS.

Компоненты вынесены в пакет `@repo/ui` и доступны для использования во всех приложениях монорепозитория.

Перед изменением интерфейса прочитайте [дизайн-систему Tracker Task](../design-system/README.md): она задаёт правила композиции страниц, типографики, тем и применения компонентов.
