# Разработчик системы

`SYSTEM_DEVELOPER` — отдельное право управления глобальными feature flags. Оно не связано с ролями `OWNER` / `ADMIN` / `MEMBER` в командах.

В серверном окружении API задайте `SYSTEM_DEVELOPER_USER_ID` равным ID существующего аккаунта разработчика. Допускается один аккаунт. Если значение пустое, управление закрыто для всех. Значение не передаётся в frontend bundle.

## Где задать ID

Это настройка окружения сервера, а не поле в таблице User. Разработчик определяется сравнением ID вошедшего пользователя с настройкой API; новая таблица или столбец роли для этого не создавались.

- **Локальная разработка (`pnpm dev`):** в `apps/api/.env` добавьте `SYSTEM_DEVELOPER_USER_ID=<User.id>` и перезапустите API. Nest ConfigModule читает .env из рабочей папки приложения API.
- **Локальный Docker (`pnpm local`):** добавьте эту строку в `apps/api/.env.local`, подключённый к api через env_file. Пересоздайте API: `docker compose -f docker-compose.local.yml up -d --force-recreate api`.
- **Stage:** задайте её в серверном `/opt/tracker/stage/.env.stage`; Compose уже передаёт значение в api. Пересоздайте API: `docker compose --env-file .env.stage -f docker-compose.stage.yml up -d --force-recreate api` из каталога stage.

Вставьте **id существующего пользователя из таблицы User**, не email и не ID команды. Его также можно получить через GET /auth/me, войдя под нужным аккаунтом. Значение храните в локальном/серверном env-файле; не добавляйте его в публичные NEXT_PUBLIC-переменные.

ID берётся из ответа `GET /auth/me` для нужного аккаунта. Настройку меняет оператор установки; после изменения требуется перезапуск API. На всех экземплярах API значение должно совпадать. Регистрация, профиль, параметры запроса и роли команд не предоставляют это право.

Управляющие endpoint-ы должны использовать сначала `JwtGuard`, затем `SystemDeveloperGuard`. Guard сравнивает ID пользователя, установленного после проверки JWT и загрузки аккаунта из БД, с серверной настройкой. Обычный пользователь получает HTTP 403, неавторизованный — HTTP 401.
